# GitProject

Dự án thực hành Git/GitHub với README và hai trang HTML.

## Cấu trúc

- `source/index.html`: trang chủ.
- `source/news.html`: trang tin, liên kết trở lại trang chủ.

## Lệnh Git

`git clone <URL>` sao chép repository remote về máy.

`git add README.md` đưa README vào staging area.

`git commit -m "Add README.md"` lưu thay đổi đã stage thành commit.

`git add source/` stage các file trong thư mục source.

`git push origin main` đẩy commit của nhánh main lên remote origin.
